Self-hosting CiteProof

Run the CiteProof research app on your own machine with Docker or a local Python environment. You bring your own language-model endpoint and search keys. The MCP server needs none of this.

Requirements

  • Docker with Compose, or Python 3.12.
  • An OpenAI-compatible language-model endpoint and its API key. The example configuration uses DeepSeek.
  • A Tavily API key for DeepSearch web search.
  • A real email address for OpenAlex and NCBI. Both services ask for one so they can reach you if a client misbehaves.

Clone and configure

git clone https://github.com/Aryan-Pardeshi/CiteProof-AI-MCP.git
cd CiteProof-AI-MCP
cp .env.example .env

Open .env and set at least these values:

VariableWhat it does
LLM_API_KEYKey for the language-model endpoint.
LLM_BASE_URLBase URL of the OpenAI-compatible endpoint, for example https://api.deepseek.com.
TAVILY_API_KEYWeb search for DeepSearch.
OPENALEX_EMAILContact address for OpenAlex, Crossref and Unpaywall requests.
NCBI_EMAIL and NCBI_TOOL_NAMEBoth are required for PubMed. If either is missing, PubMed is skipped.

Optional keys raise rate limits or recover more full texts: SEMANTIC_SCHOLAR_API_KEY, NCBI_API_KEY (3 to 10 requests per second) and CORE_API_KEY. Set ORCID_AUTHOR_ENRICHMENT=1 to canonicalise leading author names through ORCID.

Key handling

.env is ignored by git. Never commit real keys. The configuration API rewrites .env, so it is off unless you opt in: set ALLOW_OPEN_CONFIG_API=1 for local work only, or set CONFIG_API_TOKEN on any deployed copy.

Run with Docker

docker compose up -d --build

Open http://localhost:8000. The container reads .env and keeps its data in a Docker volume.

Run for development

python -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn backend.app.main:app --reload --port 8000

Where your data lives

Run state, the model cache and generated figures are written to local paths set in .env: RESEARCH_DB_PATH (default ./data/research_state.db), LLM_CACHE_PATH and FIGURES_DIR. Nothing is sent anywhere except to the language-model and academic services you configured.

Time, cost and limits

  • DeepSearch takes about 5 to 10 minutes. Research Mode takes about 15 to 25 minutes and pauses at three review gates.
  • Cost depends on the model endpoint you choose. CiteProof sets no usage cap of its own in a self-hosted copy.
  • Academic APIs and model providers have their own rate limits and outages. A run that fails at one stage can usually be retried.

The MCP server is separate

CiteProof MCP runs on your computer with npx -y citeproof-mcp and needs no model key, search key or app server. See the Claude Science setup page.
